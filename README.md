# Live Character Counter

A text box with a character count that updates live, with every key you press.

**Live demo:**  https://ordinaryphantom-lgtm.github.io/Live-Character-Counter/

![Live Character Counter screenshot](Character-Counter.png)

## Features

- The count updates instantly as you type, paste or delete
- Spaces are counted as characters
- Simple, clean card design

## Built with

- HTML
- CSS
- JavaScript (no libraries)

## What I learned

- Reacting to typing with the `input` event
- Reading what a user typed with `.value`
- Counting characters with `.length`
- Writing the result back to the page with `textContent`

## Run it on your computer

1. Download or clone this repo
2. Open `index.html` in your browser
